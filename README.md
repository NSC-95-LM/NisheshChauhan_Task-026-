# NisheshChauhan_Task(26)

## Summary
This project is a basic Vite + React application that showcases a responsive gallery of themed cards. Each card displays an image, title, and short description for a unique subject such as animals, mythology, landmarks, astronomy, and culture.

## What it Does?
The app renders a 3-column card grid with animated gradient borders and modern styling. It is designed to demonstrate a simple React component structure, reusable card components, and image-based content presentation.

## Project Structure
- `src/App.jsx` – main page layout and card collection
- `src/components/Card.jsx` – reusable card component
- `src/assets/` – image assets used in the gallery
- `src/input.css` – Tailwind import and custom animation styles
- `index.html` – app entry HTML file
- `package.json` – project scripts and dependencies

## How to Run?
1. Open the project folder in the terminal.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Open the local URL shown in the terminal in your browser.
